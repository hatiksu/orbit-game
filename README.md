# Орбита — аркада в одно касание

Неоновая браузерная игра на Canvas. Ты летаешь по орбите вокруг планеты. Касание срывает тебя по касательной,
и нужно поймать орбиту следующей планеты. Задержишься на одной планете — она разрушится.

**Стек:** TypeScript, Canvas 2D, React 19 (интерфейс), Motion, Web Audio API, Vite, vite-plugin-pwa, Vitest, Playwright.

## Как играть

- **Касание** (или пробел) — сорваться с орбиты по касательной.
- **Поймай орбиту** следующей планеты: долетел до неё — захват.
- **Не медли:** кольцо вокруг планеты — таймер. Когда он закончится, планета разрушится.
- **Вход по касательной** даёт «Идеально!» и растит комбо: каждый следующий идеальный захват приносит больше очков.
- **Звёзды** — +2 очка. **Астероиды** кружат вокруг планет: выбирай момент для прыжка.
- Сложность растёт: планеты меньше и дальше, вращение быстрее, появляются качающиеся планеты и астероиды.
- На компьютере: пробел — прыжок, P или Esc — пауза. Рекорд сохраняется на устройстве.

## Как устроено

```
src/
├── game/                 игра без React и DOM
│   ├── types.ts          мир — обычные данные
│   ├── world.ts          шаг симуляции: орбиты, полёт, захват, разрушение, звёзды, астероиды
│   ├── generator.ts      генерация уровня с ростом сложности
│   ├── rng.ts            детерминированный генератор случайных чисел (mulberry32)
│   ├── config.ts         баланс в одном месте
│   ├── audio.ts          звуки, синтезированные Web Audio
│   └── render/           Canvas-рендер и эффекты (частицы, шлейф, тряска)
├── hooks/useGame.ts      игровой цикл на requestAnimationFrame, ввод, рекорд
├── components/           Menu, Hud, PauseOverlay, GameOver, IconButton
└── lib/storage.ts        рекорд и настройки звука
```

- **Детерминированность.** Физика идёт фиксированными шагами по 1/120 с, а состояние генератора случайных чисел
  хранится в мире. Одинаковое зерно и одинаковые нажатия дают одинаковую игру на любом экране и при любой частоте кадров.
- **Производительность.** Свечение рисуется заранее подготовленными спрайтами, а не через `shadowBlur`.
  Холст учитывает плотность пикселей (до 2×), невидимые объекты не рисуются, старые планеты удаляются.
- **Интерфейс отдельно от игры.** React показывает меню и счёт и обновляется только при изменении очков,
  а не каждый кадр.
- `?seed=42` в адресе фиксирует уровень, `?debug` даёт доступ к состоянию мира для тестов.

## Команды

```bash
npm install      # зависимости
npm run dev      # dev-сервер
npm run build    # проверка типов и сборка в dist/
npm run preview  # собранная версия с Service Worker
npm run lint     # линтер
npm test         # unit-тесты (Vitest)
npm run test:e2e # E2E-тесты на компьютере и телефоне (Playwright)
```

## Тесты

- **Unit (Vitest):** детерминированность генератора, корректность уровня (планеты в поле, орбиты не пересекаются,
  звёзды не лежат на орбитах), запуск по касательной, разрушение планеты, промах, ограничение длинного кадра.
  **Бот-автопилот** проходит 15+ планет на шести разных уровнях — так проверяется, что уровни проходимы.
- **E2E (Playwright, компьютер и iPhone 13):** меню, разрушение планеты, прохождение касаниями (автопилот
  в браузере нажимает на экран) и сохранение рекорда, пауза кнопкой и клавишей, пробел, звук, работа без интернета.
- **CI:** `.github/workflows/ci.yml` на каждый пуш и PR запускает линтер, проверку типов, сборку и все тесты.

## Деплой и портфолио

`.github/workflows/deploy.yml` публикует игру на GitHub Pages при пуше в `main`.
`portfolio.json` описывает карточку проекта — сайт-портфолио подтягивает её автоматически.
